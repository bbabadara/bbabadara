## Profil

Je suis **Badara Ba**, développeur Fullstack intéressé par la conception de logiciels maintenables, les architectures robustes et l'automatisation des déploiements.

J'aime comprendre un problème, structurer une solution, écrire du code lisible, tester les composants et mettre en place des chaînes de livraison fiables. Je m'intéresse particulièrement à l'architecture logicielle, au Backend, au Cloud et aux pratiques DevOps.

- **Backend :** Java, Spring Boot, Node.js, Express, PHP
- **Frontend & mobile :** JavaScript, TypeScript, Angular, HTML5, Flutter
- **Architecture :** Architecture hexagonale, DDD, SOLID, Clean Code, API REST
- **DevOps & Cloud :** Docker, Kubernetes, Terraform, Ansible, AWS, CI/CD
- **Qualité & observabilité :** GitHub Actions, SonarQube, Prometheus, Grafana, OpenTelemetry

## Principes d'architecture

Je privilégie une séparation claire des responsabilités : l'interface communique avec les cas d'utilisation, le domaine porte les règles métier et l'infrastructure implémente les détails techniques.

<div align="center">
<img src="assets/architecture.svg" alt="Schéma d'architecture en couches concentriques et chaîne CI/CD" width="100%"/>
</div>

Quelques sujets que j'explore et applique dans mes projets :

- Architecture hexagonale et séparation domaine / infrastructure
- Domain-Driven Design (DDD) et conception d'API
- SOLID, Clean Code, tests automatisés et TDD
- Conteneurisation, orchestration et Infrastructure as Code
- CI/CD, observabilité et sécurité de la chaîne logicielle
